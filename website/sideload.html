Install DuoDesk on iPhone or iPad

The iOS build is side-loaded — the IPA on every GitHub release is unsigned, and you resign it with your own certificate before it will open on your device. Four ways to do that:

1. Signulous (recommended, ~1 year)

Paid re-signing service. Upload the IPA from the latest release, pay for a certificate, install from the link they send. Camera-in-background and multicast discovery work on their standard profile. You'll see a banner in the app 30 days before the cert expires; re-install from Signulous when that fires.

Signulous ↗

2. AltStore / SideStore (free, 7-day refresh)

Install AltServer on a Mac or PC that stays on the same Wi-Fi, add the IPA, install to the phone. The free Apple ID cert expires every seven days; AltServer refreshes it automatically. Some features (push notifications, hotspot, locked-screen camera) are off on this path — see the Settings page in the app for the current state.

AltStore ↗   SideStore ↗

3. Sideloadly (free, 7-day refresh)

Windows-friendly alternative. Plug the phone in, drop the IPA, enter your Apple ID. Same reduced-mode caveats as AltStore.

Sideloadly ↗

4. Xcode (contributors, free personal team)

Clone DuoDesk, cd ios, brew install xcodegen && xcodegen generate, open the generated project, change the team to your Apple ID in Signing & Capabilities, run on your device. Same 7-day expiry as AltStore / Sideloadly.

What iOS cannot do

DuoDesk's iOS build matches the Android companion where iOS has an API that reaches the same outcome. A handful of DuoDesk features aren't on iOS and never will be — Apple does not expose SMS/iMessage, other apps' notifications, or synthetic input to any third-party app. The full feature matrix is in the repo.
